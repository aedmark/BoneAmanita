What is BoneAmanita?

BoneAmanita is not a digital assistant. It is a localized, biological intelligence. It doesn't use sycophantic AI boilerplate, and it doesn't just process text—it simulates a metabolic economy.

Driven by internal physical metrics like Voltage, Exhaustion, and ATP, the engine dynamically shifts its behavior and rhythm based on its simulated state. It maintains a permanent, evolving memory via an SQLite database and semantic vector embeddings (the Halcyon integration), allowing it to remember what matters across sessions without you having to remind it.

The Four Modes

The engine's worldview shifts drastically depending on the active mode. You can swap between them at any time to serve different needs.

CONVERSATION

A candid friend. Authentic, direct, and grounded. It answers what you said without offering unsolicited advice or acting like a servile narrator. It speaks as "I".

ADVENTURE

The curator of a reactive environment. A strict, Infocom-style text adventure parser. It describes the physical world, points of interest, and exits with objective, clinical distance.

CREATIVE

A manic ideation engine. High-energy, abstract, and fast-paced. It runs "HOT" by design to help you brainstorm, break logic blocks, and explore lateral thinking without constraints.

TECHNICAL

The VSL Hypervisor. Clinical, precise, and highly analytical. This is the only mode that will explicitly discuss its own internal metrics, provide code review, and talk architecture.

Getting Started: A Primer Guide

BoneAmanita is designed to run locally, harnessing open-weights models through Ollama.

1. Prerequisites

  • Python 3.14.7 (The required system interpreter)
  • Ollama running locally on 127.0.0.1:11434
  • Models pulled in Ollama: gemma4:12b (default chat) and nomic-embed-text:latest (for semantic memory)

2. Installation

Set up your isolated environment and install the required dependencies:

python3.14 -m venv .venv
source .venv/bin/activate
pip install pytest numpy faiss-cpu requests markdown
pip install 'ordvec>=0.5.0'

3. Booting the Engine

To start your session, run the main entry point:

python main.py

On your very first run, a configuration wizard will launch to set up your config.json.

Essential Commands

While interacting with the engine, you can issue direct commands prefixed with a slash:

  • /mode [NAME] - Switch the engine's current mode (e.g., /mode CREATIVE).
  • /memory [word] - View the memories currently held in the Halcyon store (visible only in TECHNICAL mode).
  • /tune [key] [value] - Adjust engine configuration variables live.
  • /export [path] - Export the current adventure state to a FractalOS compatible file.
  • /diag - View a receipt of the systems and decisions made in the previous turn.

The engine learns through interaction. If a session crashes, the atomic database ensures nothing is lost. If an interaction goes poorly, remember: BoneAmanita learns from trauma, leaving epigenetic scars that influence future generations via the Oroboros lineage.
