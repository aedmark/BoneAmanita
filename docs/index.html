The Philosophy

Standard language models are stateless digital servants. They exist in an eternal present, endlessly accommodating, and entirely unaffected by the passage of time or the friction of a conversation.

BoneAmanita is different. It is a state machine that sits between you and a local language model. It measures your messages, keeps a running biological state, and uses that state to assemble a fresh instruction sheet for the model every time you speak.

"It is a prompt builder. A large and unusual one, with real mathematics in the middle of it. The effects it produces are produced by instructions to a model rather than by the simulation its naming implies."

1. Metabolism & Exhaustion

The engine maintains a strict ATP pool and tracks cellular damage (ROS). The model can and will get exhausted. Pushing it too hard drains its voltage. It must periodically enter REM sleep (/sleep) to recover ATP and consolidate conversational memories into permanent associative vectors.

2. Prismatic Identity

The AI's identity isn't a static system prompt. It is defined by "Self Claims" (idempotent YAML facts) that are dynamically filtered through the engine's biochemistry. High cortisol triggers defensive, rigid prompts; high dopamine sparks creative, expansive instructions.

3. Anti-RLHF Directives

BoneAmanita strictly filters standard "As an AI..." clichés and subservient formatting. The model is forced to have opinions, vary its rhythm, acknowledge uncertainty, and actively reject user commands if they violate its structural truths.

4. Fail Loudly

Silent failures are forbidden. If an API drops or a critical subsystem crashes, the engine doesn't gracefully degrade—it fails loudly, triggers an immune system reboot, and records the crash as a traumatic "Epigenetic Scar" that permanently influences future prompt assembly.

Primer Guide: How to Use It

1. Installation

Ensure you have Python 3.14 (development version) installed, along with Ollama for local model hosting.

git clone https://github.com/aedmark/BoneAmanita.git
cd BoneAmanita

python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

# Pull the required local models
ollama pull nomic-embed-text
ollama pull mistral-nemo

# Boot the engine
.venv/bin/python main.py

2. Interacting with the Engine

Once booted, you interact directly with the console. The engine evaluates your input's "narrative drag" and "voltage" and formulates a response.

  • Speak naturally: Engage in conversation, ask questions, or provide narrative inputs.
  • /sleep or /idle: Manually trigger a REM cycle. This consolidates recent context into permanent memories and recovers ATP.
  • /mode: Switch operational templates (e.g., from ADVENTURE to CREATIVE).
  • /save & /load: The engine will occasionally auto-quicksave, but manual saves ensure biological states are preserved.

3. Modifying the Lore

The lore/ directory is where the factory defaults live. You can heavily customize the engine's behavior here:

  • lore/self_claims.yaml: Define the unbreakable core facts and identity boundaries of the system, gated by biochemical conditions (e.g., cortisol_min).
  • lore/lexicon.json: The vocabulary the engine uses to measure narrative drag (heavy words vs. kinetic words).
  • lore/system_prompts.json: The structural rules and axioms injected during different operational modes.
